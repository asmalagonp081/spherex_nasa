## Team: Black Hole_Sun
### Challenge: Planet X and SPHEREx

### SPHEREx Movement Object Visualizator SxMOV
Python Streamlit App with public access

It allows users to view photometric images and spectra from the SPHEREx mission for a specific region of the sky at different times, searching by coordinates or identifier, connecting to the SIMBAD database, and comparing the visible spectrum with GAIA data. This application facilitates the observation of objects moving relative to the background stars and helps classify the regions of the sky where such objects are observed.
